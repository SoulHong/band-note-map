밴드 노트 지도 (Band Note Map) — 내려받아 쓰는 버전
=====================================================

열기
----
1. 이 폴더 그대로 둔 채 index.html 을 Chrome 또는 Edge 로 엽니다(더블클릭).
   폴더 안의 app.js 와 samples 폴더가 함께 있어야 소리가 나요.
2. 처음 한 번 아무 곳이나 클릭하면 소리가 켜져요.
   실제 악기 소리(약 9MB)는 화면이 뜬 뒤 뒤에서 불러와요. 그 사이엔 합성음으로 나요.
3. 인터넷이 없어도 돼요. 글꼴만 인터넷이 있을 때 더 예쁘게 보여요.

MIDI 건반(마스터 키보드) 연결
-----------------------------
1. 재생·설정 패널의 [MIDI] 버튼을 누르고, 브라우저가 물으면 '허용'을 누릅니다.
2. USB 건반: 꽂으면 바로 잡혀요. 페이지를 연 뒤에 꽂아도 돼요.
3. 블루투스 건반: 먼저 컴퓨터(운영체제)에 MIDI 장치로 연결해야 브라우저에 보여요.
   - Mac: 'Audio MIDI 설정' 앱 → 윈도우 > MIDI 스튜디오 보기 → 블루투스 아이콘에서 [연결]
   - Windows: 블루투스로 페어링해도 브라우저에 안 보일 수 있어요(Windows 블루투스 MIDI 지원이
     브라우저·버전마다 달라요). 이때는 USB 케이블이나 건반 제조사의 블루투스 MIDI 앱을 쓰세요.
   - Android: 블루투스 MIDI 연결 앱으로 먼저 연결한 뒤 Chrome 에서 여세요.
   - iPhone / iPad / Safari: 브라우저가 MIDI 를 지원하지 않아 쓸 수 없어요.
4. 건반을 치면 지금 고른 탭(드럼·베이스·건반)의 악기로 소리 나고, REC 가 켜져 있으면 피아노 롤에 기록돼요.
   - 드럼 탭: GM 드럼 배치(C1 킥, D1 스네어, F#1 하이햇 …). 어느 옥타브에서 쳐도 같은 이름 자리의 악기.
   - 베이스 탭: 베이스 음역(E0~G1)에 맞게 옥타브만 옮겨요.
   - 건반 탭: 친 음 그대로. 서스테인 페달 지원.

MIDI 버튼에서 '막힘'이 뜰 때
--------------------------
- 주소창 왼쪽 사이트 정보 아이콘 → 사이트 설정 → 'MIDI 장치'를 허용으로 바꾸고 다시 누르세요.
- 그래도 안 되면 start-server.bat 을 더블클릭하세요. 이 컴퓨터 안에서만 쓰는 작은 서버를 켜고
  http://localhost:8780/ 로 페이지를 열어 줘요(설치 필요 없음, 창을 닫으면 꺼짐).
- claude.ai 의 아티팩트 링크로 연 화면에서는 보안상 MIDI 를 쓸 수 없어요. 이 폴더 버전을 쓰세요.

폴더 구성
--------
index.html          페이지
app.js              동작 코드
samples/*kit.js     페이지가 쓰는 악기 소리 묶음(드럼·업라이트 베이스·일렉 베이스·피아노)
samples/*.wav 등    원본 WAV 사본(참고용, 페이지 동작에는 필요 없음)
samples/CREDITS.txt 샘플 출처와 라이선스(모두 CC0 퍼블릭 도메인)

화면 배치와 마지막으로 연 탭은 이 브라우저에 기억돼요.

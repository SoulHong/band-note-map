서스테인 ○ 소프트 ● 아직 페달 신호를 받지 못했어요. 페달을 밟아 보세요.
마지막 신호: 없음
페달을 밟아도 반응이 없을 때
  • ‘마지막 신호’에 컨트롤 CC가 한 번도 안 뜨면, 건반이 페달 신호를 컴퓨터로 보내지 않는 거예요. 페이지 설정으로는 고칠 수 없어요.
  • 페달 플러그를 건반의 SUSTAIN(또는 PEDAL) 단자에 끝까지 꽂은 뒤, USB를 뺐다가 다시 꽂아 건반을 다시 켜세요. 많은 건반이 켜질 때 페달을 인식해요.
  • 그래도 안 되면 건반 설명서나 제조사 설정 앱에서 페달 기능이 서스테인(CC 64)으로 되어 있는지 확인하세요.
  • CC 64가 아닌 다른 번호가 뜨면 ‘페달 신호 찾기’를 누르고 페달을 밟으세요.
  • 페달 신호가 끝내 안 오면 대신 악기 패널 위의 서스테인 스위치를 누르거나, ` 키(숫자 1 왼쪽)를 누르고 있으세요. 페달과 똑같이 음이 이어져요.
USB·블루투스 건반 연결 방법
  • USB: 케이블을 꽂으면 자동으로 잡혀요. 이미 열어 둔 페이지에도 바로 나타나요.
  • Mac 블루투스: ‘Audio MIDI 설정’ 앱 → 윈도우 메뉴의 ‘MIDI 스튜디오 보기’ → 블루투스 아이콘(Bluetooth 구성)에서 건반을 연결하면 여기에 나타나요.
  • Windows 블루투스: 설정에서 페어링해도 브라우저에 안 보일 수 있어요(Windows의 블루투스 MIDI 지원이 브라우저·버전에 따라 달라요). 그럴 땐 USB 케이블이나 건반 제조사의 블루투스 MIDI 앱·드라이버를 쓰세요.
  • Android: 블루투스 MIDI 연결용 앱으로 건반을 먼저 연결한 뒤 Chrome에서 여세요.
  • iPhone·iPad·Safari: 브라우저가 MIDI를 지원하지 않아 쓸 수 없어요.
